# Дизайн-система WBDarkstore

## 1. Цвета (DSColors)

| Токен | Значение | Назначение |
|---|---|---|
| `primary` | `#BF22E1` | Акцентный цвет (средний тон градиента) |
| `gradientStart` | `#ED3CCA` | Начало градиента (розовый) |
| `gradientEnd` | `#6600FF` | Конец градиента (фиолетовый) |
| `background` | `Color.white` | Основной фон экранов |
| `secondaryBackground` | `.systemGray6` | Фон полей ввода |
| `textPrimary` | `Color.black` | Основной текст (цены, заголовки) |
| `textSecondary` | `Color.gray` | Второстепенный текст (рейтинг, вес товара) |
| `error` | `Color.red` | Сообщения об ошибках |

Цвета взяты напрямую из макета Figma (палитра "Gradient/Violet"), а не подобраны приблизительно.

### Градиент (DSGradients)

Используется на основных CTA-кнопках ("Оформить", "В корзину"). Составлен из 8 цветовых стопов оригинального градиента Figma:
`#ED3CCA → #DF34D2 → #D02BD9 → #BF22E1 → #AE1AE8 → #9A10F0 → #8306F7 → #6600FF`

Направление: слева направо (`.leading` → `.trailing`).

## 2. Типографика (DSTypography)

| Токен | Размер / вес | Назначение |
|---|---|---|
| `title` | 32pt, medium | Заголовки экранов и крупных секций ("От Дарксора") |
| `price` | 18pt, semibold | Цена товара |
| `headline` | 14pt, medium | Названия категорий, второстепенные заголовки |
| `body` | 14pt, regular | Обычный текст, поля ввода, описания |

Размеры сверены вручную с реальным макетом в Figma, а не взяты приблизительно.

## 3. Компоненты

### DSButton
Основная кнопка действия с поддержкой градиентного фона.
- Параметры: `price: String?` (опционально), `title: String`, `isLoading: Bool`, `action: () -> Void`
- Если `price` передан — отображается слева, заголовок действия — справа (например: "900 ₽ ... Оформить")
- Если `price` не передан — заголовок центрируется на всю ширину (например: "Войти", "В корзину")
- Фон — `DSGradients.violet`, скругление 14pt, высота 50pt

### DSTextField
Поле ввода текста/пароля.
- Параметры: `placeholder: String`, `text: Binding<String>`, `isSecure: Bool`
- Стиль: фон `secondaryBackground`, скругление 14pt, высота 50pt
- Поддерживает `SecureField` для паролей

### DSCard
Универсальный generic-контейнер-карточка (`<Content: View>`).
- Принимает произвольный контент через `@ViewBuilder`
- Стиль: белый фон, скругление 16pt, мягкая тень (`black.opacity(0.06)`, radius 8)
- Используется как обёртка формы логина

## 4. Принципы

1. **Единый источник правды** — все цвета и шрифты берутся из `DSColors`/`DSTypography`/`DSGradients`, никаких магических чисел прямо во View
2. **Цвета и размеры — из реального макета**, а не приблизительные оценки — сверены вручную с Figma
3. **Компоненты — переиспользуемые и составные** — `DSCard` принимает произвольный контент через `@ViewBuilder`
4. **Согласованные отступы и радиусы** — скругление 14pt для интерактивных элементов (кнопки, поля), 16pt для контейнеров (карточки)

## 5. Пример использования — экран логина

`LoginView` целиком собран из компонентов дизайн-системы:
- `Text` с `DSTypography.title` — название приложения
- `DSCard` — контейнер формы
- `DSTextField` × 2 — логин и пароль
- `DSButton` — кнопка входа с состоянием загрузки (`isLoading`)

После успешного входа `Router.replace(with: .catalog)` переключает `NavigationStack` на `CatalogView`, используя единый стек навигации, управляемый через `ServiceLocator`.
